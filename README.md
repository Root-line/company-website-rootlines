# Rootline Company Website

Responsive Rootline consulting website with the supplied Rootline video introduction, About, services, Our Approach, and Contact sections.

## Preview

Serve this folder with any static web server and open index.html. The site has no framework or build dependencies.

## Deploy to Netlify

Connect this repository. Leave the build command blank and use the repository root as the publish directory. netlify.toml includes the static publish configuration and response headers.

## Video and accessibility

The supplied video is optimized as rootline-intro.mp4. It plays silently and includes replay and skip controls. Device reduced-motion preferences and the manual Reduce motion control show rootline-video-poster.jpg without starting the video. The original black Rootline logo remains in the header.
